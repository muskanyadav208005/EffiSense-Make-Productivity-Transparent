\# Human vs Scripted Keystroke Classification



This module is part of \*\*EffiSense – Making Productivity Transparent\*\*. It focuses on analyzing keyboard interaction patterns to distinguish between \*\*genuine human typing activity\*\* and \*\*scripted/automated typing behavior\*\*.



\## Project Objective



The goal is to build a machine learning-based classification system that can analyze keystroke patterns and classify typing activity as:



\- \*\*Human\*\* – typing behavior generated by a real user.

\- \*\*Scripted\*\* – typing behavior generated by automation or scripts.



This module can help EffiSense identify abnormal or automated activity when analyzing productivity-related user interactions.
